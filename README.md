# 라피네코딩 기질·학습 성향 궁합 테스트

라피네코딩컴퓨터학원 두정점(천안)의 **신규 학부모 상담용 단독 웹앱**입니다.
어머니 8문항 + 아이 8문항, 총 16문항으로 두 사람의 기질을 비교하고, 아이에게 맞는 코딩 트랙과 24주 커리큘럼, 무료 체험수업 방식을 안내합니다.

- 배포 주소: https://raffinegold.github.io/rafine-mind/
- 로그인 없이 바로 사용 (입력한 이름은 브라우저 안에서만 쓰이고 전송되지 않습니다)
- 외부 라이브러리 없음 — `index.html` 단일 파일 (HTML + CSS + JS)

## 구성

| 항목 | 내용 |
| --- | --- |
| 4개 축 | 탐색·실행 속도 / 구조·규칙 선호 / 표현·소통 에너지 / 오류·완성 민감도 |
| 문항 | 어머니 8 + 아이 8 (축별 2문항, 4점 척도) |
| 유형 | 어머니 4유형(M1~M4) × 아이 4유형(K1~K4) = 16가지 조합 |
| 결과지 | 궁합 타이틀, 4축 레이더·바 차트, 부딪히는 지점, 대화 예시, 수업·가정 10분 루틴, 추천 트랙 + 24주 커리큘럼, 무료 체험수업 매칭, 원장 상담 가이드 |
| 결과 코드 | `RC-XXXX` (어머니 유형 / 아이 유형 / 어머니 4축 방향 / 아이 4축 방향) |
| 복사 | 「결과 요약 복사(카톡 상담 전송용)」, 「결과 코드만 복사」, 상담 오프닝 멘트 복사 |

## 결과 코드 읽는 법

```
RC-14A3
 │  ││  └─ 아이 4축 높낮이 (4비트 hex, 1 = 높은 쪽)
 │  │└──── 어머니 4축 높낮이
 │  └───── 아이 유형 (1~4 → K1~K4)
 └──────── 어머니 유형 (1~4 → M1~M4)
```

축 순서는 `속도 · 구조 · 표현 · 민감`입니다. 결과 화면의 원장 가이드에 코드 해설이 함께 표시되어,
`라피네 클래스` 학생 프로필에 유형(M/K)과 축 방향만 입력하면 상담 맥락이 그대로 이어집니다.
