# 라피네코딩 기질·학습 성향 궁합 테스트

라피네코딩컴퓨터학원 두정점(천안)의 **신규 학부모 상담용 단독 웹앱**입니다.
어머니 8문항 + 아이 8문항으로 두 사람의 기질을 비교하고, 아이에게 맞는 코딩 트랙과 24주 커리큘럼, 무료 체험수업 방식을 안내합니다.
바쁜 상담 자리에서는 **아이만 1분 간편 진단(8문항)** 으로 시작할 수 있습니다.

- 배포 주소: https://raffinegold.github.io/rafine-mind/
- 로그인 없이 바로 사용 (입력한 이름은 브라우저 안에서만 쓰이고 전송되지 않습니다)
- 외부 라이브러리 없음 — `index.html` 단일 파일 (HTML + CSS + JS)
- 카톡·SNS 공유 미리보기용 `og-image.png` (1200×630)

## 두 가지 진단

| 모드 | 문항 | 결과지 |
| --- | --- | --- |
| 엄마 + 아이 2분 풀버전 (기본·추천) | 16문항 (엄마 8 + 아이 8) | 궁합 타이틀·궁합 온도·4축 비교·부딪히는 지점·수업/가정 루틴·추천 트랙·체험수업 매칭 |
| 아이만 1분 간편 진단 | 8문항 (아이만) | 아이 유형·4축 성향·수업/가정 안내·추천 트랙 + 24주 커리큘럼·체험수업 매칭 |

아이만 모드의 결과지에는 엄마×아이 궁합 카드가 나오지 않고, 대신 "엄마 문항까지 함께 보면 궁합 해석이 추가됩니다" 안내와
**엄마 문항 8개 더 답하기** 버튼이 있습니다. 누르면 이미 답한 아이 문항은 유지한 채 엄마 문항만 이어서 답하고 풀버전 결과지로 넘어갑니다.

## 구성

| 항목 | 내용 |
| --- | --- |
| 4개 축 | 탐색·실행 속도 / 구조·규칙 선호 / 표현·소통 에너지 / 오류·완성 민감도 |
| 문항 | 어머니 8 + 아이 8 (축별 2문항, 4점 척도) |
| 유형 | 어머니 4유형(M1~M4) × 아이 4유형(K1~K4) = 16가지 조합 |
| 결과지 | 궁합 타이틀, 4축 레이더·바 차트, 부딪히는 지점, 대화 예시, 수업·가정 10분 루틴, 추천 트랙 + 24주 커리큘럼, 무료 체험수업 매칭 |
| 결과 코드 | `RC-XXXX` (어머니 유형 / 아이 유형 / 어머니 4축 방향 / 아이 4축 방향) · 아이만 모드는 `RC-0K0X` |
| 복사 | 「결과 요약 복사(카톡 상담 전송용)」, 「결과 코드만 복사」 |

> 학부모에게 링크로 보내는 결과지이므로, 원장용 설득 포인트·이탈 신호 같은 내부 상담 메모는 결과지와 인쇄물 어디에도 넣지 않습니다.
> 상담 멘트가 필요하면 상담 기록에 결과 코드와 유형만 남기고, 해석은 원장이 직접 합니다.

## 결과 코드 읽는 법

```
RC-14A3
 │  ││  └─ 아이 4축 높낮이 (4비트 hex, 1 = 높은 쪽)
 │  │└──── 어머니 4축 높낮이
 │  └───── 아이 유형 (1~4 → K1~K4)
 └──────── 어머니 유형 (1~4 → M1~M4)
```

아이만 간편 진단은 어머니 자리를 `0`으로 비웁니다. 예: `RC-0309` → 아이만 진단 · 아이 K3(규칙·설계형) · 아이 축 높낮이 `09`.
축 순서는 `속도 · 구조 · 표현 · 민감`입니다.
