# 라피네코딩 기질·학습 성향 궁합 테스트

라피네코딩컴퓨터학원 두정점(천안)의 **신규 학부모 상담용 단독 웹앱**입니다.
어머니 8문항 + 아이 8문항으로 두 사람의 기질을 비교하고, 아이에게 맞는 코딩 트랙과 24주 커리큘럼, 무료 체험수업 방식을 안내합니다.
바쁜 상담 자리에서는 **아이만 1분 간편 진단(8문항)** 으로 시작할 수 있습니다.

- 배포 주소: https://raffinegold.github.io/rafine-mind/
- 로그인 없이 바로 사용 (입력한 이름은 브라우저 안에서만 쓰이고 전송되지 않습니다)
- 외부 라이브러리 없음 — `index.html` 단일 파일 (HTML + CSS + JS)
- 카톡·SNS 공유 미리보기용 `og-image.png` (1200×630)

## 두 가지 진단

| 모드 | 문항 | 결과지 |
| --- | --- | --- |
| 엄마 + 아이 2분 풀버전 (기본·추천) | 16문항 (엄마 8 + 아이 8) | 궁합 타이틀·궁합 온도·4축 비교·부딪히는 지점·수업/가정 루틴·추천 트랙·체험수업 매칭 |
| 아이만 1분 간편 진단 | 8문항 (아이만) | 아이 유형·4축 성향·수업/가정 안내·추천 트랙 + 24주 커리큘럼·체험수업 매칭 |

아이만 모드의 결과지에는 엄마×아이 궁합 카드가 나오지 않고, 대신 "엄마 문항까지 함께 보면 궁합 해석이 추가됩니다" 안내와
**엄마 문항 8개 더 답하기** 버튼이 있습니다. 누르면 이미 답한 아이 문항은 유지한 채 엄마 문항만 이어서 답하고 풀버전 결과지로 넘어갑니다.

## 구성

| 항목 | 내용 |
| --- | --- |
| 4개 축 | 탐색·반응 속도(숙고 설계 ↔ 즉각 도전) / 구조·규칙 지향성(자유 확산 ↔ 체계 수렴) / 정서·표현 에너지(내면 몰입 ↔ 외현 소통) / 완성·자극 민감도(유연 수용 ↔ 세밀 완벽) |
| 문항 | 어머니 8 + 아이 8 (축별 2문항, 4점 척도) · 모두 집·학교·놀이의 일상 장면 |
| 유형 | 어머니 4유형(M1~M4) × 아이 4유형(K1~K4) = 16가지 조합 |
| 결과지 | 궁합 타이틀, 4축 레이더·바 차트, 부딪히는 지점, 대화 예시, 수업·가정 10분 루틴, 추천 트랙 + 24주 커리큘럼, 무료 체험수업 매칭 |
| 결과 코드 | `RC-XXXX` (어머니 유형 / 아이 유형 / 어머니 4축 방향 / 아이 4축 방향) · 아이만 모드는 `RC-0K0X` |
| 복사 | 「결과 요약 복사(카톡 상담 전송용)」, 「결과 코드만 복사」 |

> 학부모에게 링크로 보내는 결과지이므로, 원장용 설득 포인트·이탈 신호 같은 내부 상담 메모는 결과지와 인쇄물 어디에도 넣지 않습니다.
> 상담 멘트가 필요하면 상담 기록에 결과 코드와 유형만 남기고, 해석은 원장이 직접 합니다.

## 이론적 바탕

Thomas & Chess의 기질(temperament) 모델이 다룬 핵심 차원을, 미술심리상담사 박종혁 원장이 코딩 학습 상담용으로 4개 행동 지표로 구조화했습니다.

| 지표 | Thomas & Chess 차원 | 낮은 쪽 ↔ 높은 쪽 |
| --- | --- | --- |
| 탐색·반응 속도 | 활동 수준 · 접근-회피 반응 | 숙고 설계 ↔ 즉각 도전 |
| 구조·규칙 지향성 | 규칙성 · 적응성 | 자유 확산 ↔ 체계 수렴 |
| 정서·표현 에너지 | 반응 강도 · 정서 표현 | 내면 몰입 ↔ 외현 소통 |
| 완성·자극 민감도 | 반응 역치 · 주의 지속성 | 유연 수용 ↔ 세밀 완벽 |

- 채점: 축마다 4점 척도 2문항 합산 → 0~100 지표. 4축 지표를 유형별 축 프로파일과 비교해 가장 가까운 경향을 대표로 삼고, 팽팽하면 프로파일 유사도로 판정. 50점 기준 위·아래 방향(↑↓)을 결과 코드에 담습니다.
- 서술 원칙: "○○형입니다" 같은 단정 대신 **"체크해 주신 일상 행동 지표로 보면 지금은 ○○ 경향이 두드러져 보여요"** 로 씁니다. 결과지 상단에는 "이 리포트는 출발점"·체험수업 1:1 정밀 매칭 안내를 둡니다.

## 문항 설계 원칙

- 질문에는 **코딩·프로그램·블록 코딩·오류·버그·게임 제작** 같은, 학원을 다녀 본 적 없는 학부모·아이가 경험해 보지 못한 소재를 쓰지 않습니다. (레고·퍼즐 같은 장난감 놀이는 일상 경험이라 사용합니다.)
- 모든 문항은 집·학교·놀이·외출·숙제처럼 누구나 겪는 장면으로, 축의 양 끝 행동이 뚜렷하게 갈리도록 씁니다.
- 모바일에서 3초 안에 읽고 누를 수 있게 한 문장 구어체로 씁니다.

## 결과 코드 읽는 법

```
RC-14A3
 │  ││  └─ 아이 4축 높낮이 (4비트 hex, 1 = 높은 쪽)
 │  │└──── 어머니 4축 높낮이
 │  └───── 아이 유형 (1~4 → K1~K4)
 └──────── 어머니 유형 (1~4 → M1~M4)
```

아이만 간편 진단은 어머니 자리를 `0`으로 비웁니다. 예: `RC-0309` → 아이만 진단 · 아이 K3(규칙·설계형) · 아이 축 높낮이 `09`.
축 순서는 `속도 · 구조 · 표현 · 민감`입니다.

## 라피네 클래스 연동 (2026-11-26)

결과지 아래에 **「이 결과를 라피네 클래스에 저장할까요?」** 카드가 있습니다.
학생 이름 + PIN(학원에서 받은 4자리)을 넣으면 수업 관리 앱 **라피네 클래스**의 ‘오늘의 원터치’에 기질이 저장되고, 그 차시의 맞춤 숙제·문제·추가 팁이 자동으로 나옵니다.

| rafine-mind 아이 유형 | 라피네 학습 기질 |
| --- | --- |
| K1 도전·실험형 | **CHALLENGER 실전·미션형** |
| K2 표현·발표형 | **CREATOR 창작·시각형** |
| K3 규칙·설계형 | **SYSTEMATIC 체계·암기형** |
| K4 몰입·관찰형 | **EXPLORER 탐구·원리형** |

- 저장은 `mind_submit` RPC(이름 + PIN 확인)로만 됩니다. PIN은 확인에만 쓰고 저장하지 않습니다.
- 보내는 값은 **아이 결과만**(K유형·4축 점수·아이만 코드 `RC-0K0X`)입니다. 어머니 문항 결과는 전송하지 않습니다.
- 한 학생이 한 시간에 10번까지 저장할 수 있습니다(도배 방지). 저장 뒤에는 결과지의 ‘라피네 클래스로 이동’ 링크로 바로 넘어갈 수 있습니다.
